# Stubborn Clone

A cartoon clone of *you* that refuses to copy you.

The page takes one snapshot, turns it into a local “imagined” face,
and animates that clone on the desk line. It does the opposite of
your wave or nod. Feint to make it match you. Score.

Nothing is uploaded. No account. Camera stays in this tab.

## Play

1. Open the Pages URL (desktop Chrome/Edge).
2. Allow the camera.
3. Sit back so your head and shoulders are visible.
4. Click **Start** — that snapshot becomes the clone’s face.
5. Wave or nod.
6. Fake one move, switch to the other while the clone is mid-animation.
7. **Imagine me again** takes a new snapshot and restyles it.

## What “AI imagination” means here

It is **on-device cartoonization** of your snapshot (posterize, ink, color crush).
It is not a cloud image model and it does not send your face anywhere.
A hosted generative restyle would need an API key and would leave this machine.
